Sync to Curiosa

Paste your session cookie from sorcerytcg.com. It is stored only in this app's data/ folder.

  1. Log in on sorcerytcg.com and open DevTools (F12) → Network.
  2. Reload the page, click any request to /api/trpc/….
  3. Under Request Headers, copy the full value of Cookie.

Your local collection is the source of truth: Curiosa quantities are set to match it. Alpha printings on Curiosa are never touched.
